# Слои для планетарного главного экрана

Приложенный к задаче арт утверждён как художественный референс. Он не
является набором независимых слоёв. Текущий прототип использует временные
векторные элементы WPF; случайные изображения из интернета не скачиваются.
Существующие официальные логотипы и арты Solaris остаются в проекте.

Эта папка задаёт контракт для будущих согласованных ресурсов. В текущем
прототипе PNG из неё автоматически не загружаются: замена векторных слоёв
потребует явного подключения ресурсов в XAML и проекте отдельным изменением.

## Какие файлы предоставить

Вся композиция основана на логическом поле **1280 × 600**. Предпочтительны
PNG в sRGB; для прозрачных слоёв нужен полноценный alpha-канал. Чтобы
избежать несовпадений, фон, пульт и оператор могут быть экспортированы на
одинаковый холст 1280 × 600 с прозрачностью за пределами своего слоя.
Вариант 2560 × 1200 допустим при той же композиции и пропорциях.

| Файл | Содержимое | Требования |
| --- | --- | --- |
| `cockpit-background.png` | Панорамное окно, космос, синяя и оранжевая чёрные дыры | Без текста, интерфейсных кнопок, планет выбора и персонажа. Отдельный дальний слой для малого параллакса; центр привязки `(640, 300)` |
| `cockpit-foreground.png` | Рама окна, пульт, мониторы и неоновая подсветка | Прозрачность поверх окна; без текста статусов и кнопок, которые отрисовывает WPF. Статичный ближний слой |
| `operator-body.png` | Сидящий спиной оператор и кресло | Без головы, которая должна вращаться отдельно; прозрачный фон, согласованное положение с пультом |
| `operator-head.png` | Голова оператора со стороны затылка | Прозрачный фон, перекрытие с шеей без щели. Точка поворота нормализована: `(0.5, 0.78)` относительно границ слоя головы |
| `planet-vanilla.png` | Оранжевая планета | Квадратный прозрачный холст; планета по центру, без названия/версии/статуса/кнопок |
| `planet-modded.png` | Фиолетовая фантастическая планета | Квадратный прозрачный холст; планета по центру, без запечённых интерфейсных элементов |

Для планет подходит холст 512 × 512 или 1024 × 1024. В текущей сцене
диаметр поверхности — **246 логических пикселей**. Центр вращения —
`(0.5, 0.5)`; масштаб при наведении применяется вокруг него же. Если
свечение уже включено в изображение, оставить вокруг диска прозрачный
запас и сообщить фактический диаметр диска, чтобы размер не изменился
при подключении.

## Необязательные отдельные слои

- `planet-vanilla-surface.png` и `planet-modded-surface.png`: текстуры
  поверхности для очень медленного вращения внутри круглой маски.
- `planet-modded-rings-back.png` и `planet-modded-rings-front.png`: задняя
  и передняя части энергетических колец, чтобы они проходили за планетой
  и перед ней.
- `planet-vanilla-atmosphere.png` и `planet-modded-atmosphere.png`: мягкое
  внешнее свечение на прозрачном фоне.
- `solar-system-logo.png`: дополнительная утверждённая стилизация надписи
  SOLARIS, если существующего официального логотипа недостаточно.

Энергетические кольца и атмосферное свечение могут остаться векторами.
Отдельные кольца следует экспортировать в одинаковом размере холста с
планетой; их общий центр должен совпадать с центром планеты. Не запекать
вращаемую поверхность, статичный свет и кольца в одну картинку, если они
должны двигаться независимо.

## Подключение к прототипу

Будущее изменение заменяет именованные векторные слои сцены:
`SpaceBackdrop`, статичный передний пульт, `OperatorBody`, `OperatorHead`
и поверхности планет в круглых масках. Геометрия кнопок и панели данных
остаётся управляемой WPF; арт не должен содержать кликабельные подписи,
профиль, новости или значения серверного статуса.

При экспорте оператора приложить небольшой файл с координатами головы,
точкой шеи и границами прозрачного слоя. Нормализованная точка `(0.5, 0.78)`
соответствует временной геометрии: для нового арта её необходимо проверить
и при необходимости явно скорректировать в XAML. Допустимый поворот
ограничивается малой амплитудой; полноценная анимация лица и скелета
для прототипа не нужна.

Дальнему слою нужен небольшой запас по краям либо аккуратно продолженный
фон: параллакс не должен открывать пустые полосы. Логический центр сцены
не должен меняться при экспорте. Финальные слои следует согласовать до
замены временной векторной композиции.

После получения слоёв следует проверить выравнивание на минимальном и
развёрнутом окне, DPI 125/150%, корректную точку поворота головы и память
на RX 580 4 ГБ. Подробный сценарий — в
[описании прототипа](../../docs/ANIMATED-PLANETS-HOME.md).
