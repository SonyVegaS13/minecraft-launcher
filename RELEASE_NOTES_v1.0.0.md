# Solaris Launcher v1.0.0

Первая публичная release-версия Solaris Launcher.

## В составе

- Windows x64 self-contained launcher.
- Minecraft 1.20.1.
- Forge 47.4.20.
- Загрузка SolarisClient.zip из GitHub Releases.
- Установка Minecraft/Forge/библиотек/ресурсов через CmlLib.
- Локальная регистрация и вход.
- Настройка выделяемой RAM 2048–4096 MB.
- SHA-256 checksum для ZIP.

## Ограничения v1.0.0

- Аккаунт пока локальный и не синхронизируется между ПК.
- Серверная авторизация Solaris ещё не подключена.
- Автообновление самого лаунчера будет добавлено отдельной версией.
