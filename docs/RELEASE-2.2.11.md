# Solaris Neon 2.2.11 — релиз

## Изменения

- Modded: автозаход на подтверждённый пользователем `solarismodded.millida.host:25565` посредством CmlLib ServerIp/ServerPort. Адрес проверки онлайна Modded обновлён.
- Forge 47.4.20 / Minecraft 1.20.1: космический фон загрузки через Simple Custom Early Loading 2.2-forge. Подписанный лицензионными условиями клиента JAR скачивается с Modrinth и проверяется по SHA-512; игра продолжает запуск при сетевой ошибке загрузки заставки.
- Сохраняется обычный режим Vanilla, существующая система установки модов и автообновления EXE.
- Дополнительный параметр Modded `darkMojangStudiosBackground:true` уменьшает вероятность красного фона. Ранний старт Forge иногда всё равно отображает краткую стандартную заставку (ограничение мода).

## Картинка Solaris

В сборке уже есть `Assets/SolarisCosmicHome.jpg`, поэтому она используется по умолчанию. Чтобы использовать **именно новый утверждённый PNG из переписки**, скачайте его из чата и сохраните под именем `solaris-loading.png` в `%APPDATA%\\Solaris` (точный путь равен `SolarisDirectories.StateDir`). При запуске Modded приложение установит этот рисунок в `game/config/simple-custom-early-loading`. Приложенное к чату изображение не было встроено в бинарник релиза: исходные байты картинки не перенесены в GitHub. После последующего копирования файла ранее созданная штатная конфигурация автоматически обновит только ссылку на фон.
