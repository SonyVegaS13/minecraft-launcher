# Безопасное тестирование Solaris Neon 2.2.10

**Важно:** официальный рабочий Solaris 2.2.9 не заменяем до финального релиза.

Для безопасного smoke-теста DEV-сборки на Windows:
1. Загрузите ZIP **не из GitHub Releases**, а из успешного *Artifacts* сборки
   `solaris-2.2-dev` → `SolarisLauncher-v2.2.10-win-x64`.
2. Распакуйте EXE в отдельный тестовый каталог; не перезаписывайте файлы
   работающего лаунчера, не запускайте EXE двойным кликом без аргумента.
3. Откройте PowerShell в тестовом каталоге и выполните:
   `& '.\SolarisLauncher.exe' --dev-test`.
4. Dev-режим не выполняет установку в
   `%LOCALAPPDATA%\Programs\Solaris Launcher`, не проверяет автообновление
   и использует отдельную папку `%APPDATA%\Solaris-Neon-Dev` для локальных
   аккаунтов, конфигов и установки тестовой игры.
5. Проверяйте локальный вход, Caps Lock, солнышко-глаз, подтверждение
   пароля, настройки RAM, 2D/3D-скины, активность и анимацию IGNITION.
   Для проверки загрузки Minecraft нужны интернет и достаточно места на диске.
6. Если не завершена проверка подписей/серверной авторизации, не используйте
   настоящие пароли и не регистрируйте реальные учётные записи в dev-режиме.

**НЕЛЬЗЯ:** запускать DEV EXE без `--dev-test` на рабочей машине до
приёмки обновления. При обычном запуске bootstrapper может предложить
установку поверх стабильного Solaris. Версия 2.2.10 ещё не опубликована как
официальный Neon Release.
