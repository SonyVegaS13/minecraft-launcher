# Solaris Neon 2.2.7 — встроенное неоновое оформление

## Исправление для всех игроков

В версии 2.2.6 экран входа и карточки в принципе поддерживали
оформление через ZIP, но на новом ПК без скачанного архива
показывался упрощённый резервный фон.

В **Solaris Neon 2.2.7** исходные изображения встроены в сам
`SolarisLauncher.exe` и доступны офлайн с первого запуска:

- `SolarisWorld`: парящие кубические острова, светящиеся фиолетовые
  водопады, золотое кольцо на небе, оранжево-пурпурный закат и Стив
  на выступе слева. Используется для входа, главного меню и Vanilla.
- `SolarisModded`: фиолетовый портал и Endermen на фоне
  сумеречных блочных островов. Используется в карточке Modded.
- Существующий пользовательский ZIP продолжает работать как
  добровольная настройка темы, но больше не нужен новым игрокам.
- Названия картинок в исходном `Solaris-Neon-UI.zip` правильно
  сопоставляются с входом/главным меню/Vanilla/Modded.

## Надёжность

- Два сжатых исходных WebP находятся в репозитории и сверяются по
  SHA256 перед Windows-сборкой.
- После проверки скрипт конвертирует их в PNG, которые компилируются
  как WPF Resource прямо в единый self-contained EXE.
- При отсутствии или повреждении любого изображения официальная
  GitHub Actions сборка завершается ошибкой: выпуск без темы невозможен.
- Официальный логотип, быстрые анимации, автоустановка, ярлык,
  обновления, локальные аккаунты и Minecraft сохранены.
- Данные игроков в `%APPDATA%\\Solaris` не удаляются и не переносятся.

## Как проверить

1. На чистом Windows ПК скачать `SolarisLauncher.exe` из релиза 2.2.7.
2. Запустить его — должен автоматически создаться рабочий ярлык.
3. Без выбора ZIP убедиться, что фон входа содержит большое золотое
   кольцо и парящие острова, как на эталонном снимке владельца.
4. Войти/создать локальный аккаунт и проверить фоны Vanilla/Modded.
5. Запустить повторно с отключённым интернетом: встроенные фоны
   по-прежнему должны появляться.
6. Запустить установленный 2.2.6 и принять обновление до 2.2.7,
   убедиться в сохранении аккаунта, ярлыка и файлов Minecraft.

**Windows CI проверила SHA256 обоих встроенных артов, успешно собрала
и опубликовала тестовые Windows-артефакты. Проверка интерфейса
на компьютере игрока остаётся следующим шагом.**
